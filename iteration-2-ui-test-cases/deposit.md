## Успешный депозит на аккаунт пользователя

**Для чего:**
Проверка возможности сделать депозит на аккаунт пользователя

**Предусловия:**

1. Пользователь создан админом
2. Пользователь авторизован в системе
3. У пользователя создан аккаунт

| № | Шаги                                                              | Ожидаемый результат                                                                                                              |
| - | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 1 | Нажать "Deposit money"                                            | Открывается страница для депозита                                                                                                |
| 2 | Нажать на строку выбора аккаунта                                  | Появляется выпадающий список с доступными пользователю аккаунтами                                                                |
| 3 | В выпадающем списке выбрать аккаунт из пресета                    | Выбранный аккаунт отображается в соответствующей строке                                                                          |
| 4 | Ввести произвольную сумму от 0.01 до 5000 в строку "Enter Amount" | Введенное значение отображается в соответствующей строке                                                                         |
| 5 | Нажать на кнопку увеличения суммы депозита                        | Сумма депозита увеличилась на 1                                                                                                  |
| 6 | Нажать на кнопку уменьшения суммы депозита                        | Сумма депозита уменьшилась на 1                                                                                                  |
| 7 | Нажать "Deposit"                                                  | Депозит происходит успешно, появляется всплывающее окно с подписью "Successfully deposited $(из шага 4) to account (из шага 3)!" |
| 8 | Отправить get запрос api/v1/customer/accounts                     | В запросе присутствует запись о депозите с суммой из шага 4 и "type": "DEPOSIT"                                                  |

## Ошибка при некорректном депозите на аккаунт пользователя

**Для чего:**
Проверка невозможности сделать депозит на аккаунт пользователя с некорректными данными

**Предусловия:**

1. Пользователь создан админом
2. Пользователь авторизован в системе
3. У пользователя создан аккаунт

| № | Шаги                                                          | Ожидаемый результат                                                                                   |
| - | ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 1 | Нажать "Deposit money"                                        | Открывается страница для депозита                                                                     |
| 2 | Нажать на строку выбора аккаунта                              | Появляется выпадающий список с доступными пользователю аккаунтами                                     |
| 3 | В выпадающем списке выбрать аккаунт из пресета                | Выбранный аккаунт отображается в соответствующей строке                                               |
| 4 | Ввести произвольную сумму больше 5000 в строку "Enter Amount" | Введенное значение отображается в соответствующей строке                                              |
| 5 | Нажать "Deposit"                                              | Депозит не происходит, появляется всплывающее окно с ошибкой "Please deposit less or equal to 5000$." |
| 6 | Отправить get запрос api/v1/customer/accounts                 | В запросе отсутствует запись о депозите с суммой из шага 4                                            |
