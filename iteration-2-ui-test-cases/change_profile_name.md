## Успешное изменение name в профиле

**Для чего:**
Проверка возможности изменить name в профиле при корреткных данных

**Предусловия:**

1. Пользователь создан админом
2. Пользователь авторизован в системе

| № | Шаги                                                                                                            | Ожидаемый результат                                                                               |
| - | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 1 | Нажать на кнопку "Noname @username" (class = "user-info" в devtools)                                            | Открывается страница редактирования профиля                                                       |
| 2 | Ввести корректно новое имя в строке "Enter new Name"<br>(Имя должно состоять из двух слов и имеет только буквы) | Введенное значение отображается в строке                                                          |
| 3 | Нажать "save changes"                                                                                           | Изменение происходит успешно, появляется всплывающее окно с подписью "Name updated successfully!" |
| 4 | Отправить get запрос api/v1/customer/profile                                                                    | В запросе значение поля name соответствует значению из шага 2                                     |

## Ошибка при изменении name в профиле с некорректными данными

**Для чего:**
Проверка невозможности изменить name в профиле при корреткных данных

**Предусловия:**

1. Пользователь создан админом
2. Пользователь авторизован в системе

| № | Шаги                                                                                                                  | Ожидаемый результат                         |
| - | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| 1 | Нажать на кнопку "Noname @username" (class = "user-info" в devtools)                                                  | Открывается страница редактирования профиля |
| 2 | Ввести некорректное новое имя в строке "Enter new Name"<br>(Имя не должно состоять из двух слов и иметь только буквы) | Введенное значение отображается в строке    |
| 3 | Нажать "save changes"                                                                                                 | Появляется всплывающее окно с ошибкой       |
| 4 | Отправить get запрос api/v1/customer/profile                                                                          | В запросе значение поля name не изменилось  |
