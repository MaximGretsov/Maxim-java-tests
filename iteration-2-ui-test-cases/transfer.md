## Успешный трансфер между своими аккаунтами

**Для чего:**
Проверка возможности перевести деньги между аккаунтами одного пользователя с корректными данными

**Предусловия:**

1. Пользователь создан админом
2. Пользователь авторизован в системе
3. У пользователя создано 2 аккаунта
4. В аккаунт 1 сделан депозит на сумму 5000
5. У пользователя в профиле изменено имя (изначально оно null)
6. Пользователь авторизован в системе

| №  | Шаги                                                                                  | Ожидаемый результат                                                                                                                                                                             |
| -- | ------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1  | Нажать на кнопку "Make a Transfer"                                                    | Открывается страница для трансфера                                                                                                                                                              |
| 2  | Нажать на строку выбора аккаунта                                                      | Появляется выпадающий список с доступными пользователю аккаунтами                                                                                                                               |
| 3  | В выпадающем списке выбрать аккаунт 1 из пресета                                      | Выбранный аккаунт отображается в соответствующей строке                                                                                                                                         |
| 4  | Ввести имя пользователя из пресета в поле "Recepient name"                            | Введенное значение отображается в поле "Recepient name"                                                                                                                                         |
| 5  | Ввести номер аккаунта 2 в поле "Recipient Account Number" (формат "ACC" + account id) | Введенное значение отображается в поле "Recipient Account Number"                                                                                                                               |
| 6  | Ввести произвольное значение больше 0 и меньше суммы на аккаунте 1 в поле "Amount:"   | Введенное значение отображается в поле "Amount:"                                                                                                                                                |
| 7  | Нажать на кнопку увеличения суммы трансфера                                           | Сумма трансфера увеличилась на 1                                                                                                                                                                |
| 8  | Нажать на кнопку уменьшения суммы трансфера                                           | Сумма трансфера уменьшилась на 1                                                                                                                                                                |
| 9  | Активировать чек-бокс "Confirm details are correct"                                   | Чек-бокс активирован                                                                                                                                                                            |
| 10 | Нажать "Send Transfer"                                                                | Трансфер происходит успешно, появляется сообщение "Successfully transferred $(из шага 6) to account (из шага 5)!"                                                                               |
| 11 | Отправить get запрос api/v1/customer/accounts                                         | В запросе для аккаунта 1 присутствует запись о трансфере с суммой из шага 6 и "type": "TRANSFER_OUT", для аккаунта 2 присутствует запись о трансфере с суммой из шага 6 и "type": "TRANSFER_IN" |

## Успешный поиск транзакции в разделе "Transfer Again"

**Для чего:**
Проверка возможности найти транзакцию по username или name пользователя

**Предусловия:**

1. Пользователь создан админом
2. Пользователь авторизован в системе
3. У пользователя создано 2 аккаунта
4. Выполнен тест с успешной транзакцией
5. У пользователя в профиле изменено имя (изначально оно null)

| № | Шаги                                                                     | Ожидаемый результат                                                                                                   |
| - | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| 1 | Нажать на кнопку "Make a Transfer"                                       | Открывается страница для трансфера                                                                                    |
| 2 | Нажать на кнопку "Transfer Again"                                        | Открывается страница для повторного трансфера                                                                         |
| 3 | В поле "Search by Username or Name:" ввести username аккаунта из пресета | Введенное значение отображается в поле "Search by Username or Name:"                                                  |

| 6 | Нажать на кнопку "Search Transactions"                                   | В разделе "Matching Transactions" остается только запись о транзакциях и депозитах пользователя с username из пресета |
