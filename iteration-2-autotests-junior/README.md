# API Tests - Iteration 2

Проект содержит автотесты для проверки API банковского приложения.

## Стек

* Java
* JUnit 5
* Rest Assured
* Maven

## Что покрыто тестами

Автотестами покрыты 3 основные ручки:

1. **Deposit** - пополнение счета пользователя
2. **Transfer** - перевод денег между счетами
3. **Profile** - изменение имени пользователя в профиле

Для каждой ручки реализованы позитивные и негативные проверки.

## Покрытые сценарии

### Deposit

Проверяется успешное пополнение счета, а также негативные сценарии:

* невалидная сумма депозита
* депозит в несуществующий аккаунт
* депозит в чужой аккаунт
* запрос без авторизации
* запрос с невалидным токеном
* невалидное тело запроса

### Transfer

Проверяется успешный перевод:

* между своими счетами
* на счет другого пользователя

Также покрыты негативные сценарии:

* перевод суммы 0
* перевод отрицательной суммы
* перевод больше максимального лимита
* перевод больше доступного баланса
* перевод с несуществующего аккаунта
* перевод на несуществующий аккаунт
* перевод с чужого аккаунта
* запрос без авторизации
* запрос с невалидным токеном
* невалидное тело запроса

### Profile

Проверяется успешное изменение имени пользователя, а также негативные сценарии:

* имя из одного слова
* имя из трех слов
* пустое имя
* имя с пробелом в начале или конце
* имя только из пробелов
* имя со спецсимволами
* имя с цифрами
* имя с дефисом
* `name = null`
* запрос без поля `name`
* запрос без авторизации
* запрос с невалидным токеном

## Известная проблема

Тест `userCannotChangeNameWithoutNameInBody` сейчас падает.

Причина: при отправке запроса без поля `name` сервер возвращает `200 OK`, хотя ожидается ошибка. В других похожих негативных сценариях при отсутствии обязательного поля сервер возвращает ошибку, поэтому текущее поведение считается багом API.

## Запуск тестов

Перед запуском тестов приложение должно быть запущено локально на порту `4111`.
